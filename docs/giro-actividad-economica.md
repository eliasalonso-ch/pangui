# Giro y descripción de actividad — Pangui

Textos para trámites ante el SII, contratos y documentos tributarios.

**Código de actividad económica:** `620100 — ACTIVIDADES DE PROGRAMACIÓN INFORMÁTICA`

> **Nota sobre el código.** En el catálogo del SII, 620100 aparece con "G" tanto
> en *Afecto a IVA* como en *Categoría tributaria*: ambas se determinan por las
> características de la actividad, porque el mismo código lo usan empresas de
> software y profesionales independientes que programan por encargo.
>
> Como SpA que comercializa licencias de uso de un software propio bajo
> suscripción, la actividad es de **Primera Categoría** y **afecta a IVA**: hay
> una organización de capital y trabajo, no el ejercicio de una profesión.
> Por eso las descripciones de abajo enfatizan *desarrollo y explotación de
> software propio*, no *servicios de programación a terceros*.

---

## 1. Giro comercial (una línea)

Para la factura electrónica, el encabezado de documentos y el registro en el SII.

```
Desarrollo, comercialización y explotación de software propio bajo modalidad
de suscripción (SaaS)
```

**Variante más corta**, si el campo tiene poco espacio:

```
Desarrollo y comercialización de software como servicio (SaaS)
```

---

## 2. Descripción breve (2–3 líneas)

Para formularios que piden algo más que el giro: apertura de cuentas, registro
en pasarelas de pago, verificación de actividad.

```
Desarrollo, mantención y explotación comercial de una plataforma informática
propia de gestión de mantenimiento (CMMS), licenciada a empresas mediante
suscripción mensual en modalidad de software como servicio (SaaS), con acceso
vía web y aplicación móvil.
```

---

## 3. Descripción completa

Para la verificación de actividad del SII, contratos, o cuando un tercero
(banco, procesador de pagos) pide detalle del negocio.

```
La empresa desarrolla, mantiene y explota comercialmente una plataforma
informática propia denominada Pangui, destinada a la gestión de mantenimiento
de activos e infraestructura (CMMS, Computerized Maintenance Management
System).

La plataforma permite a sus clientes administrar órdenes de trabajo,
mantenimientos preventivos y correctivos, inventario de repuestos,
procedimientos de trabajo, activos e instalaciones, y obtener indicadores de
gestión asociados a su operación.

El servicio se presta bajo modalidad de software como servicio (SaaS): el
cliente no adquiere el software, sino un derecho de uso temporal sobre la
plataforma alojada en la infraestructura de la empresa, accesible mediante
navegador web y aplicaciones móviles.

La comercialización se realiza mediante suscripciones de cobro mensual
recurrente, tarificadas según la cantidad de usuarios activos del cliente y el
plan contratado. Los pagos se recaudan a través de plataformas de pago
autorizadas y cada cobro se documenta con la emisión de factura electrónica
afecta a IVA.
```

---

## 4. Elementos por si un formulario los pide sueltos

| Campo | Valor |
|---|---|
| Código de actividad | 620100 |
| Actividad | Actividades de programación informática |
| Categoría tributaria | Primera Categoría |
| Afecto a IVA | Sí (19%) |
| Modalidad | Software como servicio (SaaS), suscripción mensual recurrente |
| Producto | Plataforma de gestión de mantenimiento (CMMS) |
| Canal | Web y aplicaciones móviles (iOS / Android) |
| Mercado | Empresas (B2B), Chile |
| Documento tributario | Factura electrónica afecta (DTE 33) |

## 5. Códigos adicionales que podrían corresponder

El SII permite declarar más de una actividad. Estos son los que se acercan al
negocio, por si conviene agregarlos:

| Código | Actividad | IVA | Cat. |
|---|---|---|---|
| `620200` | Actividades de consultoría de informática y de gestión de instalaciones informáticas | SI | 1 |
| `620900` | Otras actividades de tecnología de la información y de servicios informáticos | SI | 1 |
| `631200` | Portales web | SI | 1 |

**Recomendación:** 620100 basta y describe correctamente la actividad
principal. Agregar 620900 tiene sentido solo si se empiezan a facturar
servicios que no son la suscripción (implementaciones, integraciones a medida,
capacitación). No conviene declarar actividades que no se ejercen: el SII las
considera al fiscalizar.

---

> **Antes de usar estos textos en un trámite**, conviene que los revise tu
> contador. La clasificación de 620100 como Primera Categoría afecta a IVA es
> la correcta para este modelo de negocio, pero la marca "G" del catálogo
> significa justamente que el SII la evalúa caso a caso.
